# STEP 7: 결제(Payment) 도메인 구현

## 작업 일시
2026-05-12 ~

## 작업 요약
토스페이먼츠 V2 연동 + 멱등성 + 정기권 발급 트랜잭션 + 환불 처리.
실제 토스 호출은 운영 프로파일, 개발은 MockTossPaymentClient.

## Phase 구성

| Phase | 내용 | 상태 |
|-------|------|------|
| 1 | 토스 API 클라이언트 추상화 (Real + Mock) | 대기 |
| 2 | Payment Entity 비즈니스 메서드 + V7 마이그레이션 | 대기 |
| 3 | 결제 사전 준비 + 승인 API (멱등성·금액검증·보상) | 대기 |
| 4 | 환불 처리 (전액/부분, 사용분 차감) | 대기 |
| 5 | 토스 웹훅 처리 (시그니처 검증 + 멱등성) | 대기 |
| 6 | 결제 이력 조회 (회원/관리자) | 대기 |
| 7 | E2E 테스트 8시나리오 + Swagger | 대기 |

## 보안 핵심
- 클라이언트 amount 절대 신뢰 X (서버에서 MembershipPass 가격 재계산)
- TOSS_SECRET_KEY 환경변수 필수, 코드 하드코딩 금지
- 웹훅 시그니처 검증 (HMAC-SHA256)
- 멱등성: orderId UNIQUE + existsByOrderId
- 보상 트랜잭션: 정기권 발급 실패 시 토스 환불 호출
