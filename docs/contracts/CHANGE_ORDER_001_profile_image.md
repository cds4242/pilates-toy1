## 변경 요약

디자인 미세 조정 5건 + 회원 프로필 사진 기능 1건을 v1에 포함하기로 합의.

## 변경 상세

### 1. 디자인 미세 조정 (추가 비용 없음)
1. 메인 핑크 채도 상향 (#F8C8DC → #F0A0B5)
2. 카드 모서리 12px → 18px
3. 본문 글씨 크기 14px → 15px
4. 관리자 대시보드 캘린더 뷰 추가
5. 로그인 화면 학원 사진 영역 추가

### 2. 회원 프로필 사진 기능 (추가 비용 발생)
- **회원 가입 시**: 프로필 사진 등록 (선택)
- **마이페이지**: 프로필 사진 변경/삭제
- **강사 출석 체크**: 회원 프로필 사진 표시
- **관리자 회원 관리**: 회원 목록에 프로필 사진 표시
- **저장소**: Cloudflare R2
- **제한**: 최대 5MB, JPG/PNG/WebP
- **리사이즈**: 서버에서 200x200, 500x500
- **미등록 시**: 이름 이니셜 + 배경색 자동 생성

## 영향 범위

### DB 변경
- `members` 테이블에 2개 컬럼 추가

  - `profile_image_uploaded_at TIMESTAMP NULL`

### 인프라 추가
- Cloudflare R2 버킷 1개

### 화면 추가/변경

- `member/mypage.html` 프로필 사진 영역 추가
- `instructor/attendance.html` 회원 사진 표시
- `admin/members.html` 프로필 컬럼 추가
