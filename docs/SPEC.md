# 필라테스 스튜디오 예약 관리 시스템 - 확정 명세

## 1. 프로젝트 개요

소규모 필라테스 스튜디오(1~3개 지점)를 위한 **예약 관리 + 회원 관리 + 수강권 관리** 웹 시스템.
원장(관리자)과 강사가 주 사용자이며, 회원은 별도 앱 없이 **카카오톡 알림톡**으로 예약 확인/변경을 수행한다.

### 핵심 가치
- 수기 관리(엑셀, 종이) → 디지털 전환
- 예약 충돌·누락 제로
- 회원 수강권 잔여 횟수 실시간 파악
- 매출·출석 통계 자동화

## 2. 사용자 역할 (Role)

| 역할 | 설명 | 주요 권한 |
|------|------|-----------|
| **SUPER_ADMIN** | 시스템 관리자 (개발자) | 전체 시스템 설정, 지점 관리 |
| **ADMIN** | 원장 / 점장 | 회원·강사·수업·수강권·매출 전체 관리 |
| **INSTRUCTOR** | 강사 | 본인 수업 스케줄 조회, 출석 체크, 회원 메모 |
| **MEMBER** | 회원 | 카카오 알림톡으로 예약 확인/취소 (웹 로그인 없음) |

## 3. 도메인 정의

### 3.1 회원 (Member)
- 이름, 연락처(휴대폰), 성별, 생년월일
- 등록일, 상태(활성/휴면/탈퇴)
- 메모 (강사가 작성하는 신체 특이사항, 주의점 등)
- 담당 강사 (선택)

### 3.2 수강권 (Ticket)
- 수강권 유형: 개인(1:1), 듀엣(1:2), 그룹(1:N), 체험
- 총 횟수, 잔여 횟수
- 유효기간 (시작일 ~ 종료일)
- 상태: 활성 / 만료 / 소진 / 일시정지(홀딩)
- 홀딩: 사유, 홀딩 기간, 홀딩 중 유효기간 자동 연장
- 금액, 결제일, 결제 방법(카드/현금/이체)

### 3.3 수업 (Lesson)
- 수업 유형: 개인 / 듀엣 / 그룹
- 수업 시간: 50분 기본 (설정 가능)
- 정원: 유형별 기본값 (개인=1, 듀엣=2, 그룹=최대 8)
- 담당 강사
- 고정 시간표 (반복 스케줄) + 단건 수업

### 3.4 예약 (Reservation)
- 회원 + 수업 시간대 매핑
- 상태: 예약확정 / 출석 / 결석 / 취소 / 노쇼
- 취소 규칙: 수업 시작 **2시간 전**까지 무료 취소 (설정 가능)
- 당일 취소 / 노쇼: 수강권 1회 차감
- 예약 시 수강권 잔여 횟수 자동 검증
- 대기 예약: 정원 초과 시 대기열, 취소 발생 시 자동 승격

### 3.5 스케줄 (Schedule)
- 주간 고정 시간표 (매주 반복)
- 강사별 근무 가능 시간
- 휴무일 / 공휴일 설정
- 스케줄 변경 시 해당 예약 건 알림

### 3.6 알림 (Notification)
- 카카오 알림톡 연동 (비즈메시지 API)
- 알림 유형:
  - 예약 확정 알림
  - 수업 전날 리마인더 (오후 8시)
  - 수업 당일 리마인더 (2시간 전)
  - 취소/변경 알림
  - 수강권 만료 임박 알림 (7일 전, 3일 전)
  - 수강권 잔여 횟수 부족 알림 (3회 이하)

### 3.7 매출/통계 (Revenue & Statistics)
- 일별/월별 매출 집계
- 수강권 유형별 매출
- 강사별 수업 횟수
- 회원 출석률
- 신규 등록 / 재등록 / 이탈 통계

## 4. 핵심 비즈니스 규칙

1. **예약 충돌 방지**: 같은 시간대에 동일 회원 중복 예약 불가
2. **수강권 검증**: 예약 시 잔여 횟수 > 0 && 유효기간 내 && 수업 유형 일치
3. **취소 페널티**: 수업 시작 2시간 이내 취소 = 1회 차감 (설정 가능)
4. **노쇼 처리**: 수업 종료 후 미출석 = 자동 노쇼 처리 + 1회 차감
5. **홀딩**: 유효기간 중 일시정지, 홀딩 일수만큼 종료일 자동 연장
6. **대기 → 확정 자동 승격**: 취소 발생 시 대기 1번 → 예약 확정 + 알림
7. **강사 스케줄 보호**: 강사 근무 가능 시간 외 수업 배정 불가

## 5. 화면 목록 (관리자 웹)

### 대시보드
- 오늘의 수업 현황 (시간대별)
- 금일 예약/출석/결석/취소 카운트
- 수강권 만료 임박 회원 리스트
- 이번 달 매출 요약

### 회원 관리
- 회원 목록 (검색, 필터, 페이지네이션)
- 회원 상세 (기본정보 + 수강권 + 예약 이력 + 메모)
- 회원 등록/수정

### 수강권 관리
- 수강권 발급 (회원 선택 → 유형/횟수/기간/금액 입력)
- 수강권 목록 (상태별 필터)
- 홀딩 처리

### 예약/스케줄 관리
- 주간 캘린더 뷰 (강사별 / 시간대별 격자)
- 예약 등록 (시간대 클릭 → 회원 선택 → 수강권 자동 매칭)
- 예약 상태 변경 (출석/결석/취소)
- 고정 스케줄 설정 (반복 수업)

### 강사 관리
- 강사 목록 / 등록 / 수정
- 근무 가능 시간 설정
- 강사별 수업 현황

### 매출/통계
- 매출 대시보드 (일별/월별 차트)
- 수강권 판매 내역
- 출석 통계

### 설정
- 스튜디오 기본 정보
- 수업 시간 단위 설정
- 취소 규칙 설정
- 알림 템플릿 관리

## 6. 기술 스택

| 영역 | 기술 |
|------|------|
| **Backend** | Java 21, Spring Boot 3.x, Spring Data JPA, QueryDSL |
| **Database** | MySQL 8.0, Redis 7 (캐시/세션) |
| **Frontend** | Next.js 14 (App Router), TypeScript, TailwindCSS, shadcn/ui |
| **상태 관리** | Zustand + React Query (TanStack Query) |
| **인증** | JWT (Access Token 30분 + Refresh Token 14일) |
| **알림** | 카카오 비즈메시지 API (알림톡) |
| **인프라** | Docker Compose (개발), 추후 클라우드 배포 |
| **CI/CD** | GitHub Actions |

## 7. 비기능 요구사항

- **응답 시간**: API 평균 200ms 이내
- **동시 사용자**: 최소 50명 동시 접속
- **데이터 백업**: 일 1회 자동 백업
- **개인정보 보호**: 연락처 마스킹 표시, 로그 내 개인정보 마스킹
- **브라우저 지원**: Chrome, Safari, Edge 최신 2개 버전
- **모바일 반응형**: 관리자 웹은 태블릿 이상 최적화

## 9. 용어 사전

| 용어 | 영문 | 설명 |
|------|------|------|
| 수강권 | Ticket | 회원이 구매한 수업 이용권 |
| 홀딩 | Holding | 수강권 일시정지 |
| 노쇼 | No-show | 예약 후 미출석 |
| 듀엣 | Duet | 1:2 수업 |
| 그룹 | Group | 1:N 수업 (최대 8명) |
| 고정 스케줄 | Fixed Schedule | 매주 반복되는 수업 시간표 |
