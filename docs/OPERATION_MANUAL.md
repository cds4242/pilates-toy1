# 운영 매뉴얼 (의뢰인용)

필라테스 스튜디오 예약 관리 시스템 운영 가이드

---

## 1. 시스템 개요

### 사용자 역할

| 역할 | 설명 | 로그인 방법 |
|------|------|------------|
| **관리자 (ADMIN)** | 원장/점장. 전체 관리 | 관리자 아이디/비밀번호 |
| **슈퍼관리자 (SUPER_ADMIN)** | 시스템 설정 포함 전체 권한 | 관리자 아이디/비밀번호 |
| **강사 (INSTRUCTOR)** | 본인 수업 관리, 출석 체크 | 관리자 탭에서 강사 계정 로그인 |
| **회원 (MEMBER)** | 예약, 정기권 조회 | 휴대폰 번호/비밀번호 |

### 화면 구성

- **관리자 화면** (PC 최적화): 대시보드, 회원관리, 수업관리, 통계
- **회원 화면** (모바일 최적화): 홈, 시간표, 정기권, 내 정보
- **강사 화면**: 스케줄, 출석 체크

## 2. 일상 운영

### 2.1 매일 확인 (대시보드)

관리자로 로그인하면 대시보드가 표시됩니다:

1. **오늘 수업**: 오늘 예정된 수업 목록 (시간, 강사, 예약 인원)
2. **이번 주 매출**: 월~일 기준 매출 합계
3. **만료 임박 정기권**: 7일 이내 만료되는 회원 목록
4. **알림**:
   - 노쇼 주의 회원 (최근 30일 노쇼 3회 이상)
   - 정기권 잔여 부족 회원 (1회 이하)

### 2.2 회원 등록

**방법 1: 개별 등록**
1. 회원이 직접 앱에서 회원가입 (휴대폰 인증 → 정보 입력)

**방법 2: 엑셀 일괄 등록**
1. 관리자 → 회원 관리 → 엑셀 일괄 등록
2. 템플릿 다운로드 → 이름, 휴대폰, 메모 입력
3. 업로드 → 부분 성공 처리 (실패 행은 사유와 함께 표시)
4. 제한: 최대 5MB, 1000행

### 2.3 정기권 발급

**방법 1: 결제 후 자동 발급**
- 회원이 결제 완료 시 정기권 자동 생성

**방법 2: 관리자 수동 발급**
1. 관리자 → 회원 상세 → 정기권 발급
2. 정기권 종류 선택 → 횟수, 금액, 유효기간 설정

**방법 3: 엑셀 일괄 발급**
- 운영 초기 또는 이벤트 시 휴대폰 번호 + 정기권 코드로 일괄 발급

### 2.4 수업 등록

**고정 스케줄 (반복 수업)**
1. 관리자 → 수업 관리 → 고정 스케줄 설정
2. 강사, 수업 유형, 요일, 시간 설정
3. 자동 생성 버튼으로 향후 N주간 수업 일괄 생성

**단건 수업**
1. 관리자 → 수업 관리 → 수업 추가
2. 날짜, 시간, 강사, 수업유형, 정원 설정

**휴강 처리**
1. 관리자 → 수업 관리 → 해당 수업 → 취소(휴강)

### 2.5 출석 체크

1. 강사 로그인 → 오늘 수업 목록
2. 수업 선택 → 예약자 리스트
3. 각 회원: 출석(ATTENDED) / 지각(LATE) / 결석(ABSENT) 마킹
4. 수업 종료 30분 후까지 마킹 가능
5. 미마킹 회원은 자동 노쇼(NO_SHOW) 처리 (스케줄러)

### 2.6 결제·환불

**결제**
1. 회원 → 정기권 선택 → 결제 (토스페이먼츠)
2. 결제 완료 시 정기권 자동 발급

**환불**
1. 관리자 → 결제 내역 → 환불 처리
2. 부분 환불 가능 (누적 환불 금액 관리)

## 3. 자주 묻는 질문 (FAQ)

### Q: 회원이 비밀번호를 잊었을 때?
A: 휴대폰 인증 후 비밀번호 재설정 가능.

### Q: 정기권 일시정지(홀딩) 신청은?
A: 관리자가 회원 상세에서 일시정지 처리. 일시정지 기간만큼 유효기간 자동 연장.

### Q: 예약 취소 정책은?
A: 수업 시작 2시간 전까지 무료 취소. 이후 취소 불가.

### Q: 같은 시간에 다른 수업 예약 가능한가요?
A: 불가. 시간 겹침 검증으로 중복 예약 차단.

### Q: 대기 예약은?
A: 정원 초과 시 대기 등록. 취소 발생 시 자동 승격 (v2 예정).

### Q: 엑셀 등록 시 중복 회원은?
A: 같은 휴대폰 번호의 기존 회원이 있으면 해당 행 실패, 나머지 정상 처리.

## 4. 통계 활용

### 매출 분석
- 관리자 → 통계 → 매출
- 기간 선택 (일별/주별/월별)
- 엑셀 다운로드 가능

### 회원 추이
- 관리자 → 통계 → 회원
- 가입자 수, 탈퇴자 수, 현재 활성 회원 수

### 출석률 관리
- 관리자 → 통계 → 출석률
- 전체 출석률, 강사별, 수업 유형별

### 인기 시간대
- 관리자 → 통계 → 인기 시간대
- 시간대별, 요일별 예약 수 → 수업 편성 참고

## 5. 알림 발송 정책

### 자동 알림 종류

| 알림 | 발송 시점 | 수신자 |
|------|----------|--------|
| 예약 확인 | 예약 즉시 | 회원 |
| 예약 취소 | 취소 즉시 | 회원 |
| 수업 1시간 전 리마인더 | 수업 시작 1시간 전 | 회원 |

| 정기권 만료 알림 | 만료 7일/3일 전 | 회원 |

1. **카카오 알림톡** (기본)
2. **SMS** (알림톡 실패 시 자동 폴백)
