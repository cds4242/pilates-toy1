# 인수인계 시연 시나리오 (30분)

---

## 준비사항

- 백엔드 실행: `cd backend && ./gradlew bootRun --args='--spring.profiles.active=local'`
- 프론트엔드 실행: `cd frontend && npm run dev`
- 브라우저: Chrome (http://localhost:3000)

---

## 1단계: 시스템 소개 (5분)

### 화면 구성 설명
- **회원 화면** (모바일): 로그인 → 홈 → 시간표 → 예약
- **관리자 화면** (PC): 로그인 → 대시보드 → 회원 관리 → 통계
- **강사 화면**: 출석 체크

### 접속 정보
| 역할 | URL | 계정 |
|------|-----|------|
| 관리자 | http://localhost:3000/login (관리자 탭) | admin / admin1234 |
| 회원 | http://localhost:3000/login (회원 탭) | 회원가입 후 사용 |

---

## 2단계: 회원 입장 시연 (10분)

### 2-1. 회원가입
1. http://localhost:3000/signup 접속
2. 휴대폰 번호 입력 → "인증번호 받기"
3. 콘솔에서 Mock 인증번호 확인 (Redis 키: `sms:code:{phone}`)
4. 인증번호 입력 → "인증 확인"
5. 이름, 비밀번호, 성별 입력 → "가입 완료"
6. 자동 로그인 → /home 이동

### 2-2. 홈 화면 확인
- 환영 메시지 + 회원명
- "활성 정기권이 없습니다" (신규 회원)
- "예정된 예약이 없습니다"

### 2-3. 시간표 조회
1. /schedule 이동 (하단 네비 "시간표")
2. 7일 날짜 선택
3. 수업 있으면 예약 버튼 표시

> 참고: 수업이 없으면 관리자로 먼저 수업 생성 필요

---

## 3단계: 관리자 입장 시연 (10분)

### 3-1. 관리자 로그인
1. /login → 관리자 탭
2. admin / admin1234 입력 → 로그인
3. /dashboard 자동 이동

### 3-2. 대시보드
- 오늘 수업 카운트
- 이번 주 매출
- 만료 임박 정기권
- 노쇼 주의 + 잔여 부족 알림

### 3-3. 회원 관리
1. 사이드바 "회원 관리" 클릭
2. 검색 (이름 또는 전화번호)
3. 회원 클릭 → 상세 페이지
   - 기본 정보 (휴대폰 마스킹)
   - 정기권 목록
   - 예약 이력
   - 출석률
   - 결제 이력
   - 메모

### 3-4. 통계
1. 사이드바 "통계" 클릭
2. 매출 통계 (일별/월별)
3. 엑셀 다운로드 → 파일 저장 확인

---

## 4단계: 강사 입장 시연 (5분)

### 4-1. 강사 로그인
- 관리자 탭에서 강사 계정으로 로그인

### 4-2. 출석 체크
- 오늘 수업 선택 → 예약자 리스트
- 각 회원 출석/지각/결석 마킹

> 참고: 수업 시간 범위 내에서만 출석 체크 가능

---

## 5단계: Q&A (5분)

### 예상 질문
- "회원이 직접 예약하나요?" → 네, 모바일 시간표에서 직접 예약
- "정기권 일시정지는?" → 관리자가 회원 상세에서 처리
- "수업 취소(휴강)하면?" → 예약자 자동 취소 + 정기권 복구
- "엑셀로 회원 일괄 등록?" → 관리자 회원 관리 → 엑셀 업로드
- "알림은 언제 가나요?" → 예약 확인/취소 즉시 + 1시간 전 리마인더 + 만료 알림
