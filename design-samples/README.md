# 필라테스 예약 시스템 - 디자인 시안 3종

## 보는 방법

1. **각 시안 폴더의 `index.html`을 더블클릭** → 브라우저에서 열립니다
2. 메뉴에서 회원 / 강사 / 관리자 페이지를 선택해 확인하세요
3. 개별 HTML 파일을 직접 더블클릭해도 됩니다

> **회원·강사 페이지**: 모바일(375px)에서 보는 것이 가장 정확합니다
> **관리자 페이지**: PC(1280px)에서 보는 것이 가장 정확합니다
> 반응형이라 한 환경에서 양쪽 다 볼 수 있습니다

## 피드백 요청

확인 후 아래 항목에 대해 편하게 말씀해주세요:

1. **어느 시안이 가장 마음에 드시나요?** (A / B / C)
2. **색상·분위기** — 바꾸고 싶은 부분이 있나요?
3. **글자 크기 / 가독성** — 읽기 편한가요?
4. **버튼 모양·색상** — 다른 시안의 버튼이 더 좋다면?
5. **추가/삭제할 화면** — 더 필요한 화면이나 빼고 싶은 부분
6. **참고 사이트** — 이런 느낌이면 좋겠다 하는 앱이나 사이트 링크
